这是什么

一个 Agent Skill：让 AI 编程助手具备「学术 PDF 中译」的完整工程能力。

📑

逐页零缺失

每个源页 / 每个 slide 对应一个输出单元，一条 bullet 都不丢；自动门禁逐页核对数字与编号。

🧮

公式原样保留

数学公式不翻译；附带 (cid:xx) 乱码速查表，把碎裂的文本层重组回正确 LaTeX。

🎨

版式完全还原

PPT 的 PDF → Beamer 16:9；讲义 → A4 ctexart。页幅、字号、边距、定理样式、编号全部按源复刻。

⚡

团队并行加速

按内容主题分片，多个子智能体同时翻译，写域互斥零冲突。263 页实测 ≈ 串行 1/7 时间。

🛡️

四重自动门禁

单元数 / 数字多重集 / 残留英文 / 环境编号逐页比对，再加人工视觉抽查才放行。

安装

三条命令装好，之后对 AI 说人话即可。

1 · 克隆到 skills 目录

      ~/.claude/skills/pdf-translator

2 · 安装依赖

# poppler-utils（pdfimages / pdftoppm）

#   macOS   : brew install poppler
#   Linux   : sudo apt-get install poppler-utils

# TeX Live / MiKTeX（需含 xelatex 与 ctex 宏包）
3 · 环境自检

python scripts/probe_pdf.py book.pdf       # 勘察 PDF

工作流程

六个阶段，每阶段都有对应工具，不靠手写临时脚本。

  1. 勘察 probe_pdf.py 判定文本版/扫描版、页幅、位图数量 → 选定 Beamer 或 ctexart 版式
  2. 解析 extract_pages.py 逐页提取为 pages.json，带上 Definition 3、Theorem 5 等环境标记
  3. 分类标记 公式 / 图表 / 表格分区；(cid:xx) 乱码按速查表重组为 LaTeX
  4. 分片 + 团队并行 make_digests.py 按主题切片，多个子智能体同时翻译，写域互斥
  5. 编译与校正 XeLaTeX 编译 → 修错 → renumber_envs.py 对齐编号 → fix_*.py 修溢出 → 复编译至 0 error
  6. 验收与交付 verify_translation.py 四重门禁 + 视觉抽查 → 交付 <Name>_中文版.pdf
